# Preprocessor symbols that mean "this is a Windows (or DOS) compiler/target".
#
# filter-tree.sh hands each one to unifdef as -U<symbol>: every #if/#ifdef/#elif
# that the symbol decides is resolved as "not defined" -- exactly what GCC and
# Clang on Linux already see -- and the dead branch is deleted. check-tree.sh
# fails on any #if/#elif line that still names one.
#
# A symbol belongs here only if NO Linux compiler predefines it and NOTHING in
# this tree #defines it (nor passes -D for it): otherwise unifdef would delete
# code the Linux build actually compiles. prove-equivalence.sh is the check that
# the list is right -- it preprocesses every source file before and after the
# filter and requires byte-identical output.
